# 우주 탐사대 (space_explorer)

중학교 과학 '별과 우주' 단원을 태블릿에서 직접 조작하며 익히는 퀘스트형 학습 웹앱입니다.

- 퀘스트 1 별: 미션 1 거리, 미션 2 밝기, 미션 3 온도
- 퀘스트 2 우주: 미션 1 우리은하의 구조, 미션 2 우리은하의 구성 천체, 미션 3 팽창하는 우주, 미션 4 우주탐사
- 퀘스트 3 6개의 밝기에서 우주로: 미션 1 우주 관측의 역사 (스텝 1 맨눈 관측 ~ 스텝 5 보이지 않는 빛, 사진은 Wikimedia Commons에서 불러옴)

각 미션은 조작 시뮬레이션과 내용정리로 이루어지며, 미션을 마치면 메인 "우주 탐사대"로 돌아와 단원 진행률을 확인합니다.

## 교사 설정
`js/main.js` 맨 위 `TEACHER_SETTINGS`에서 퀘스트 공개 범위를 바꿀 수 있습니다.

## 파일 구성
- `index.html` 메인, `quest1.html`·`quest2.html`·`quest3.html` 퀘스트 화면
- `style.css` 공통 스타일 (외부 CDN 없음)
- `js/main.js` 진행도·잠금 공통 코드, `js/dnd.js` 끌어놓기, `js/quest.js` 퀘스트 화면 진행
- `js/sim/` 미션별 시뮬레이션
